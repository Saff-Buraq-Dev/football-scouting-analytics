# Data attribution assets

`statsbomb-logo.png`: official StatsBomb logo ("SB - Icon Lockup - Colour positive"), downloaded on
2026-10-05 from StatsBomb's own open-data repository:
https://github.com/hudl/open-data/blob/master/img/SB%20-%20Icon%20Lockup%20-%20Colour%20positive.png

used only for this attribution.
